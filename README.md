# LRC Lyrics

**Виджет панели Plasma 6: показывает строку песни, которая сейчас поётся, а если источник
отдаёт пословные тайминги — ещё и подсвечивает слово.**

[![aur](https://img.shields.io/aur/v/plasma-lrc?label=aur&logo=archlinux&style=flat)](https://aur.archlinux.org/packages/plasma-lrc)
[![license](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)
[![plasma](https://img.shields.io/badge/plasma-6-1d99f37?style=flat-square)](https://kde.org/plasma-desktop/)

```
  панель
  ┌───────────────────────────────────────────────┐
  │ ♪  And this lil' ho talk too much             │
  └───────────────────────────────────────────────┘
        спето — приглушено, текущее слово — подчёркнуто

  клик по виджету — окно: трек, строка целиком, автор синхронизации
```

Источников два, и виджет сам переключается между ними: пока есть тайминги слов от
API, процесс `lrc_tty` не запускается вовсе.

---

## Что умеет

- **Строка на панели.** Обрезается по длине или по числу символов. Панель никогда не
  схлопывается, даже когда текста нет: апплету ширину отдают один раз и обратно не
  возвращают.
- **Подсветка слова.** Целиком, а не по кускам, из которых слово было собрано.
  Уже спето — приглушено, поётся сейчас — подчёркнуто или жирно (на выбор).
- **Сам выбирает плеер.** MPRIS есть и у голосовых сообщений Telegram, поэтому виджет
  смотрит на метаданные, а не на имя: у музыкального трека есть длина, альбом и
  обложка, у голосового ничего этого нет.
- **Не лезет в сеть зря.** Ответы API лежат в `~/.cache/plasma-lrc/spicy/` 30 дней,
  отсутствие трека запоминается на сутки.
- **Не держит чужой текст.** При смене трека панель пустеет, а не показывает последнюю
  строку предыдущей песни; за концом последней строки тоже пустеет.
- **Догоняет перемотку.** Позиция сверяется с плеером каждые 400 мс, поэтому после
  перемотки панель показывает то, что звучит, а не то, что было полминуты назад.
- **Подсказка** с исполнителем и названием трека.
- **Окно по клику** с треком, строкой и ссылкой на автора синхронизации.

## Требования

| | |
|---|---|
| Plasma | 6.x (KDE Frameworks 6) |
| `lrc_tty` | для поиска лирики в lrclib — [lrc_tty](https://github.com/larsgrah/lrc_tty) |
| Ключ Spicy Lyrics | необязательно, нужен только для пословной подсветки на Spotify |

Собирать самому: CMake 3.20+, Ninja, компилятор с C++17, Qt 6.5+.

## Установка

### Arch Linux

```sh
yay -S plasma-lrc
```

Ставится в систему, `plasmashell` перезапускается сам. Виджет появляется в
«Добавить виджеты».

### Вручную из репозитория

```sh
git clone https://github.com/skippingclass/plasma-lrc
cd plasma-lrc
./install.sh                # собрать, поставить, перезапустить plasmashell
./install.sh --no-restart   # без перезапуска
./uninstall.sh              # снести всё: пакет, библиотеку, настройки, виджет с панели
```

### Из исходников

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
sudo cmake --install build
systemctl --user restart plasma-plasmashell.service
```

Виджет ставится в два места, как это делают все applet-плагины Plasma:

```
/usr/lib/qt6/plugins/plasma/applets/org.kde.plasma.lrc.so
/usr/share/plasma/plasmoids/org.kde.plasma.lrc/
```

Пользовательская установка в `~/.local` не работает: Plasma ищет applet-плагины
только в `QCoreApplication::libraryPaths()`, а `~/.local/lib` туда не входит.

После установки: правый клик по панели → **Добавить виджеты** → **LRC Lyrics**.

## Настройки

Правый клик по виджету → **Настроить…**. Страницы: Lyrics, Source, Appearance.

### Lyrics

| Настройка | Зачем |
|---|---|
| **Update every** | Как часто спрашивать строку, 200…10000 мс. По умолчанию 200. Каждый тик — один запуск `lrc_tty`; не успел — тик пропускается. Когда строка приходит из API, интервал ни на что не влияет. |
| **lrc_tty executable** | Путь к программе, если она не в `$PATH`. |
| **MPRIS player** | Пусто — авто-определение. Можно указать конкретный, например `spotify`. |
| **Never ask** | Плееры, которые не опрашивать вообще (через запятую). |
| **Lyric offset** | Сдвиг лирики, −2000…+2000 мс. Для синков, которые стабильно спешат или опаздывают; подсветка едет вместе с текстом. |
| **Timestamps** | Префиксовать строку её таймкодом. |
| **Idle** | Не запускать `lrc_tty`, пока ничего не играет. Выключите, если хотите, чтобы виджет подхватывал трек мгновенно. |

### Source

| Настройка | Зачем |
|---|---|
| **Spicy Lyrics** | Спрашивать API для пословных таймингов, когда играет Spotify. |
| **API key** | Ключ вида `sl_sk_…`. |

### Appearance

Иконка, подсказка, текст «нет слов», максимальная длина строки и то, чем выделяется
текущее слово — подчёркиванием или жирным.

## Spicy Lyrics

[spicylyrics.org](https://spicylyrics.org) отдаёт лучший доступный синк для трека
Spotify: пословный от сообщества, иначе Apple Music, иначе сам Spotify. Без ключа не
работает, получить можно на
[developers.spicylyrics.org](https://developers.spicylyrics.org).

Ключ вписывается в настройках или экспортируется в окружении:

```sh
export SPICY_LYRICS_SECRET_KEY=sl_sk_...
```

Переменная имеет приоритет и не светится в конфиге Plasma — если ключ лежит там
открытым текстом, это стоит знать.

Пока Spicy отвечает, `lrc_tty` не запускается вообще. Если API не знает трек или у
него нет таймингов, виджет молча возвращается к `lrc_tty` — так и работает поиск по
названию для всего, что не Spotify.

Откуда взялись слова, виджет говорит: в панели коротким суффиксом `· Spicy Lyrics`,
который при наведении раскрывается до имени автора, а в окне — полной ссылкой.

Зеркало API задаётся `SPICY_LYRICS_API_ROOT` (по умолчанию
`https://api.spicylyrics.org/v1/lyrics/`).

## Если что-то не работает

**Панель пустая, хотя музыка играет.** Проверьте, что `lrc_tty` на месте и знает
плееры: `lrc_tty --list-players`. Если в выводе вашего плеера нет, укажите его имя в
`MPRIS player` явно.

**Виджета нет в списке «Добавить виджеты».** Проверьте, что установлены обе части:

```sh
ls /usr/lib/qt6/plugins/plasma/applets/org.kde.plasma.lrc.so
ls /usr/share/plasma/plasmoids/org.kde.plasma.lrc/
```

и что после установки перезапущен `plasmashell`.

**Панель показывает старую версию виджета.** Библиотека уже замаплена в работающий
`plasmashell`, поэтому нужен перезапуск:

```sh
systemctl --user restart plasma-plasmashell.service
```

**Слова не совпадают со звуком.** Сдвиг синхронизации: Lyrics → **Lyric offset**,
шаг 50 мс, вправо — позже.

**Слова не подсвечиваются вовсе.** У источника нет пословных таймингов (у lrclib их
почти нет), нужен ключ Spicy Lyrics и Spotify. Источник всегда видно в подсказке.

**Подсвечиваются чужие строки** — скорее всего, виджет выбрал плеер, который
только выглядит медиаплеером. Lyrics → **Never ask**.

**Посмотреть, что происходит.** Виджет запускается и отдельно от панели:

```sh
plasmawindowed org.kde.plasma.lrc
QT_QPA_PLATFORM=offscreen plasmawindowed org.kde.plasma.lrc   # вообще без окон
```

## Как это работает

Коротко: апплет на C++ спрашивает у MPRIS-плеера, что играет, и держит позицию
воспроизведения; QML только рисует. Отсюда три следствия, которые видно снаружи:

- **Почему нет процесса при Spotify.** Позиция и тайминги приезжают из API, и виджет
  считает всё сам по монотонным часам, сверяясь с плеером каждые 400 мс.
- **Почему перемотка не ломает панель.** MPRIS не сообщает о перемотке ничем, поэтому
  это единственный способ её заметить — и единственный источник дрожи, поэтому сверка
  частая, а доверие к ней — большое.
- **Почему строка не всегда та.** Названия из браузера и YouTube приходят с мусором
  («[Official Video]», «4K», «| Lyrics video», «Artist - Topic»), а поиск идёт по
  словам, поэтому название чистится перед запросом.

Подробности — в [docs/how-it-works.md](docs/how-it-works.md): выбор плеера, синхронизация
позиции, разбор ответа API и грабли, на которые там наступали.

## Для разработчика

```sh
cmake -S . -B build -G Ninja -DPLASMA_LRC_TESTS=ON
cmake --build build
./build/spicy-parser-test
```

Тесты разбирают ответы API вживую — это единственное место, где баг стоит тишины:
не разобрал ответ, и виджет решил, что трека нет. Тем же бинарником можно пропустить
сохранённый ответ и посмотреть, что из него получилось:

```sh
./build/spicy-parser-test answer.json
```

```
lrcapplet.{h,cpp}     апплет: MPRIS, QProcess, позиция, таймеры
spicylyrics.{h,cpp}   клиент Spicy Lyrics: HTTP, разбор ответа, кэш
trackname.{h,cpp}     чистка названий перед поиском в lrclib
contents/ui/          QML: панель, окно, страницы настроек
contents/config/      main.xml (значения по умолчанию) + config.qml
tests/                проверки парсера
docs/                 как это работает внутри
```
