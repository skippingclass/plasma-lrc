## Возможности

- **Многоисточниковый конвейер текстов (Multi-Source Pipeline)**:  
  Модульный движок с настраиваемым приоритетом опроса и переключателями источников. Поддерживает бесплатные открытые источники без токенов с послоговой синхронизацией Apple Music TTML (`lrc.red` и `AMLL TTML DB`), а также `Spicy Lyrics` и `LRCLIB`. При отсутствии таймингов у источника виджет мгновенно переходит к следующему провайдеру в цепочке.
- **Пословное караоке в реальном времени**:  
  Каждое поющееся слово подсвечивается синхронно с вокалом прямо на панели задач Plasma благодаря послоговым таймингам Apple Music TTML (`lrc.red`, `AMLL`) и Spicy Lyrics. Слоги объединяются в слова без разрывов и скачков текста.
- **Кастомная палитра и цвета подсветки**:  
  Возможность задать любой HEX-цвет подсветки (`#RRGGBB`) или выбрать готовый пресет в 1 клик (Spotify Green, Cyan, Purple, Yellow, Coral, White). Стили: цвет выделения, полужирный шрифт или подчёркивание.
- **Разовая загрузка текста (1 запуск на трек вместо 900)**:  
  Вместо спама фоновыми процессами каждые 200 мс виджет считывает полный текст песни ровно один раз при смене трека. Позиция интерполируется локально монотонными часами `QElapsedTimer` на C++ — нагрузка на процессор составляет 0% CPU на холостом ходу.
- **Умный MPRIS-движок**:  
  Автоматически определяет активный плеер, не лочится на браузерных вкладках (YouTube), срезает клиповый мусор из названий (`[Official Video]`, `4K`, `| Lyrics video`) и мгновенно переключается на музыку.
- **Чистая панель на паузах и проигрышах**:  
  Во время длинных гитарных соло, битов и в интро панель остаётся чистой и не держит фантомные старые строки. При остановке воспроизведения текст мягко исчезает через заданный таймер (по умолчанию 5 сек).
- **Настраиваемые клики мыши**:  
  Левый клик (окно трека / Play-Pause), средний клик колесом (ничего / Play-Pause / следующий трек).
- **Окно текста песни и ручное копирование**:
  Окно полного текста песни (**Open song lyrics…**) поддерживает все источники лирики без таймкодов и караоке-разметки. Для треков API доступно обычное экранное выделение текста мышью и копирование через Ctrl+C, тогда как кнопки быстрого копирования (**Copy all lyrics**, **Copy selection** и пункт контекстного меню **Copy current lyric line**) зарезервированы исключительно для нативного источника LRCLIB. В виджете нет функций скачивания файлов, экспорта или эндпоинтов получения сырого ответа API.
- **Обязательное указание авторства**:
  Полная атрибуция провайдера обязательна на всех поверхностях (панель, всплывающее окно и окно полного текста / ридер). Имя провайдера отображается всегда, а отдельные кликабельные ссылки на создателя (maker) и загрузчика (uploader) синхронизации выводятся при наличии данных источника (`source=spicy_lyrics`, провайдеры Spotify и Apple Music). Всплывающая подсказка панели показывает данные трека, плеер и провайдера без дублирования строки песни. Атрибуцию API нельзя скрыть. Для нативного источника LRCLIB указание авторства отображается только в попапе и окне песни, не занимая место на панели. На панели доступны два варианта расположения: **Right of lyrics** («Справа от текста», по умолчанию) и **Below lyrics** («Под текстом», для стандартных панелей от 30px).
- **Жёсткий срок хранения кэша и приватность**:
  Все сохранённые ответы API имеют максимальный срок хранения 30 дней, а данные с неизвестным или неположительным сроком жизни отклоняются. Записи удаляются при запуске виджета, при обращении к кэшу и во время периодической очистки при работе приложения (снимки в оперативной памяти и открытом окне текста также истекают по таймеру; фоновое удаление при выключенном приложении или компьютере невозможно). Построчный синк обновляется каждые 2 дня для обнаружения новых пословных синхронизаций сообщества.
- **Плавные визуальные переходы**:  
  Мягкая анимация затухания между строками песни без мерцания во время пословного караоке.
- **Экспериментальный бэк-вокал**:
  Опциональное отображение отдельной строки бэк-вокала с независимой пословной синхронизацией, автоматической адаптацией под 30px панель и поддержкой во всплывающем окне.

## Архитектура и как это работает

```
┌────────────────────────────────────────────────────────┐
│               MPRIS2 Media Player (D-Bus)              │
│       Spotify / Firefox / Chromium / Strawberry        │
└───────────────────────────▲────────────────────────────┘
                            │ Смена трека / Metadata / Position (400 мс)
┌───────────────────────────┴────────────────────────────┐
│                  LrcApplet (C++ Core)                  │
├────────────────────────────────────────────────────────┤
│ 1. Детекция смены трека & Скоринг активного плеера     │
│ 2. Конвейер источников (Цепочка приоритетов):          │
│    ├── 1. lrc.red (слоговый синк Apple Music TTML)     │
│    ├── 2. AMLL TTML DB (база сообщества через CDN)     │
│    ├── 3. Spicy Lyrics (пословный синк Spotify)        │
│    └── 4. LRCLIB (открытая построчная база)            │
│ 3. Парсеры TTML и LRC (C++): парсинг в память          │
│ 4. QElapsedTimer: локальный тайминг строк и слов       │
└───────────────────────────┬────────────────────────────┘
                            │ Текст, текущее слово, прогресс
┌───────────────────────────▼────────────────────────────┐
│                 QML UI (KDE Plasma 6)                  │
│        Строка панели + Попап + Окно текста (Reader)    │
└────────────────────────────────────────────────────────┘
```

## Установка

### Arch Linux (AUR)

> [!NOTE]
> *Будет доступно после публикации — ожидается открытие регистрации в AUR из-за текущих ограничений.*

```bash
yay -S plasma6-applet-lrc-git
```

### Быстрая установка скриптом

```bash
git clone https://github.com/skippingclass/plasma-lrc.git
cd plasma-lrc
./install.sh                # собрать, установить в систему и перезапустить панель
./install.sh --no-restart   # собрать и установить без перезапуска plasmashell
./uninstall.sh              # удалить виджет, плагин и настройки
```

### Сборка вручную через CMake

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
sudo cmake --install build
systemctl --user restart plasma-plasmashell.service
```

### Добавление на панель
1. Нажмите правой кнопкой мыши по панели Plasma → **«Добавить виджеты...»** (*Add Widgets*).
2. Найдите **Plasma LRC** и перетащите на панель задач.

## Настройки

Правый клик по виджету на панели → **«Настроить виджет...»**:

### Вкладка «Внешний вид» (Appearance)

| Параметр | По умолчанию | Описание |
|---|---|---|
| **Поющееся слово** | `Подчёркивание` | Стиль караоке: `Подчёркивание`, `Жирный` или `Цвет выделения`. |
| **Цвет выделения** | *(Акцент KDE)* | Кастомный цвет активного слова. Кнопки-пресеты: Spotify (`#1ed760`), Cyan (`#00d4ff`), Purple (`#b342f5`), Yellow (`#ffd600`), Coral (`#ff4d4d`), White (`#ffffff`). |
| **Анимация** | `Включено` | Плавное затухание/появление текста при смене строк. |
| **Выравнивание** | `По центру` | Выравнивание текста в виджете: `По центру` или `Слева`. |
| **Credit layout** | `Right of lyrics` | Расположение атрибуции на панели для источников Spicy API: `Right of lyrics` (справа от текста, по умолчанию) или `Below lyrics` (под текстом, для стандартных панелей от 30px). Атрибуция Spicy API обязательна на всех поверхностях (панель, попап, окно текста) и не скрывается; для нативного LRCLIB авторство отображается только во всплывающем окне и в окне текста. |
| **Макс. длина** | `40 символов` | Ограничение длины строки в символах для экономии места на панели (0 = без ограничений). |
| **Текст-заглушка** | `♪` | Что отображать на панели, когда ничего не играет. |
| **Иконка** | `Включено` | Показывать ноту рядом с текстом. |
| **Подсказка** | `Включено` | Показывать название трека, исполнителя, плеер и провайдера во всплывающей подсказке (без дублирования строки текста). |

### Вкладка «Текст и синхронизация» (Lyrics)

| Параметр | По умолчанию | Описание |
|---|---|---|
| **Частота опроса** | `2000 мс` | Интервал проверки состояния плееров (500–10000 мс). |
| **Любимый плеер** | *(пусто)* | Предпочитать этот плеер при одновременном воспроизведении (например, `spotify`). |
| **Привязать к плееру** | *(пусто)* | Работать исключительно с указанным плеером и игнорировать остальные. |
| **Сдвиг тайминга** | `0 мс` | Корректировка (−2000…+2000 мс) для спешащих или отстающих треков. |
| **Игнорировать** | *(пусто)* | Список MPRIS-источников через запятую (например, плееры уведомлений). |
| **В простое** | `Выключено` | Останавливать опрос, когда ничего не играет (0% CPU в простое). |
| **Скрытие на паузе** | `5 секунд` | Через сколько секунд скрывать текст при паузе (0 = не скрывать). |
| **Клик ЛКМ** | `Открыть окно` | Действие по левому клику: `Открыть окно` или `Play / Pause`. |
| **Клик СКМ** | `Play / Pause` | Действие по клику колёсиком: `Ничего`, `Play / Pause`, `Следующий трек`. |
| **Временные метки** | `Выключено` | Показывать `[mm:ss]` перед строкой. |

### Вкладка «Чёрный список» (Blacklist)

| Параметр | По умолчанию | Описание |
|---|---|---|
| **Заблокированные треки** | *(пусто)* | Список названий песен или `Артист - Название` через точку с запятой, для которых не нужно искать текст. Также переключается через контекстное меню или попап. |

### Вкладка «Источники» (Source)

| Параметр | По умолчанию | Описание |
|---|---|---|
| **Spicy Lyrics** | `Включено` | Запрашивать пословные караоке-тайминги из Spicy Lyrics API для Spotify. |
| **API key** | *(пусто)* | Персональный клиентский ключ `sl_pk_…`, получаемый каждым пользователем через шаблон приложения в каталоге. |

## Настройка Spicy Lyrics (Пословное караоке)

Сервис [spicylyrics.org](https://spicylyrics.org) предоставляет пословные караоке-тайминги для треков Spotify:

1. Для публично распространяемого нативного виджета предусмотрено получение **каждым пользователем собственного клиентского ключа** (`sl_pk_…`) через шаблон приложения в [каталоге Spicy Lyrics](https://developers.spicylyrics.org/catalog) (шаблон настраивается для нативных клиентов без заголовка Origin). Общий встроенный секретный ключ в виджете не используется.
2. Шаблону приложения требуется одобрение для размещения в каталоге; прямая ссылка на шаблон появится здесь после одобрения. Виджет не содержит и не распространяет общие ключи, а личные ключи разработчика не должны передаваться третьим лицам или служить каналом дистрибуции.
3. Укажите полученный клиентский ключ в настройках виджета (**Источники → API key**) или через переменную окружения:

```bash
export SPICY_LYRICS_SECRET_KEY=sl_pk_...
```

*Переменная окружения сохраняет своё историческое имя `SPICY_LYRICS_SECRET_KEY` для обратной совместимости, принимает клиентские ключи (`sl_pk_…`), и её название не означает, что требуется секретный ключ. Она имеет приоритет над GUI-настройками.*

### Хранение данных и ограничения API

- **Жёсткий срок жизни кэша:** локально сохранённые ответы API удаляются не позднее 30 дней с момента записи, а полезная нагрузка с неизвестным или неположительным сроком действия отклоняется. Очистка устаревших файлов происходит при старте виджета, при обращении к кэшу и периодически во время работы (снимки в оперативной памяти и открытом окне текста также истекают; фоновое удаление при выключенном компьютере или закрытом приложении невозможно).
- **Обновление построчного синка:** кэш для треков с построчной синхронизацией обновляется каждые 2 дня, чтобы вовремя подхватывать добавленные пословные тайминги сообщества.
- **Отсутствие экспорта:** в виджете нет функций скачивания, сохранения файлов на диск или эндпоинтов выгрузки сырых ответов API. Кнопки автоматического копирования текста зарезервированы только для открытого источника LRCLIB; для API доступно лишь обычное экранное выделение текста и ручное копирование (Ctrl+C).

Если API сообщает о приостановке приложения (`application_suspended`), выдача кэшированных текстов API блокируется до получения нового успешного ответа HTTP 200 от авторизованного приложения. Смена токена не снимает приостановку на уровне приложения. При обычных сетевых сбоях и ошибках лимитов (HTTP 429) непросроченный локальный кэш продолжает отдаваться. Нативный поиск LRCLIB продолжает полноценно работать независимо от статуса API. Существующий локальный кэш никому не передаётся и удаляется по стандартному расписанию истечения срока.

## Если что-то не работает

- **Панель пустая, хотя музыка играет:**  
  Убедитесь, что ваш медиаплеер поддерживает стандарт MPRIS2 и сейчас воспроизводит трек. Если плеер не определяется автоматически, укажите его имя в поле **Любимый плеер** (например, `spotify` или `chromium`).
- **Слова не подсвечиваются пословно:**  
  Пословная подсветка доступна для Spotify через Spicy Lyrics. Для остальных источников (LRCLIB) текст синхронизируется построчно.
- **Слова спешат или отстают от звука:**  
  Откройте настройки виджета → вкладка **Текст** → настройте ползунок **Сдвиг тайминга** (вправо — задержка, влево — опережение).
