## Ключевые возможности

- **Послоговое караоке в реальном времени**: Плавная подсветка каждого спетого слога и слова прямо на панели задач Plasma без скачков разметки и задержек. Поддержка Apple Music TTML (`lrc.red`, `AMLL`), QQ Music QRC, KuGou KRC, NetEase YRC и Spicy Lyrics.
- **Интерактивный выбор другого совпадения («Choose another match…»)**: Окно поиска альтернативных текстов по всем 7 онлайн-источникам с индикаторами типа синка (**Word**, **Line**, **None**), устойчивостью к лимитам запросов (HTTP 429), многоуровневым кэшированием (5 мин свежий / 30 мин резерв) и ручным закреплением за треком.
- **10 модульных провайдеров**: Гибкая цепочка приоритетов с автоматическим переходом к следующему источнику: локальные файлы, lrc.red, LRCLIB, NetEase Cloud Music, KuGou, Unison, Spicy Lyrics, AMLL TTML DB, QQ Music и собственный HTTP API.
- **Защита от декомпрессионных бомб и перегрузки**: Жесткий контроль входящих данных (`LyricsLimits`): мгновенное прерывание загрузки при ответе более 8 МиБ, лимит 16 МиБ на распакованный текст, до 10 000 строк, 100 000 слов и 16 384 символов в строке.
- **Субмиллисекундная точность (0% CPU в простое)**: Текст запрашивается **один раз** при смене песни. Локальный тайминг рассчитывается монотонным таймером `QElapsedTimer` с формулой компенсации задержки MPRIS (`Base + Elapsed - Lead - audioLead - Offset`).
- **Вторичный бэк-вокал**: Вторая строка вокала в круглых скобках с независимой синхронизацией слов, градиентом яркости от серого к белому и адаптацией под высоту панели.
- **Подробная диагностика синхронизации**: Встроенное окно телеметрии (**«Diagnostics…»**) с отображением живой формулы задержек MPRIS, статусов источников, причин отклонения кандидатов, уровней кэша и безопасным копированием отчета в буфер обмена.
- **Очистка служебных строк и титров**: Автоматическое удаление непоющихся секций (`[Куплет]`, `[Припев]`, `[Intro]`, `[Chorus]`) и информации об авторах (`Written by:`, `作词：`) с сохранением невидимых временных границ.
- **Паузы, интро и соло**: Автоматическое определение вступлений (`♪ Intro ♪`) и инструментальных проигрышей (`♪ Instrumental ♪`) с возможностью отображения значка ноты или сохранения чистой панели.

## Матрица поддерживаемых провайдеров

| Провайдер | Качество синка | Форматы | Авторизация | Описание |
|:---|:---:|:---:|:---:|:---|
| **Локальные файлы** | Word / Line | `.ttml`, `.lrc` | Не требуется | Файлы рядом с треком, в `~/.lyrics`, `~/Music/lyrics` или произвольной папке. |
| **lrc.red** | Word (Слоги) | TTML, LRC | Не требуется | База Apple Music TTML со слоговой синхронизацией, поиском по ISRC и резервным LRC. |
| **LRCLIB** | Line | Synced LRC | Не требуется | Быстрая открытая база синхронизированных текстов со скорингом совпадения метаданных. |
| **NetEase Cloud Music** | Word / Line | YRC, LRC | Не требуется | База NetEase со слоговой синхронизацией YRC и стандартным LRC. |
| **KuGou Music** | Word / Line | KRC, LRC | Не требуется | Движок KuGou с запатентованным сжатым форматом KRC и резервным LRC. |
| **Unison** | Word / Line | TTML, LRC | Не требуется | Сервис Unison (`boidu.dev`) с поддержкой TTML-синка и LRC. |
| **Spicy Lyrics** | Word (Слоги) | Native API | Бесплатный ключ | Синхронизация треков Spotify из каталога Spicy Lyrics с политикой хранения до 30 дней. |
| **AMLL TTML DB** | Word (Слоги) | TTML | Не требуется | База Apple Music Like Lyrics через глобальные CDN-зеркала jsDelivr. |
| **QQ Music** | Word / Line | QRC, LRC | Не требуется | Музыкальная база QQ Music со слоговым шифрованным форматом QRC и fallback на LRC. |
| **Свой эндпоинт** | Настраиваемый | JSON / Текст | По выбору | Произвольный HTTP API с макросами `{title}`, `{artist}`, `{album}`, `{durationMs}` и `{spotifyId}`. |

## Установка

### Arch Linux (AUR)

```bash
yay -S plasma6-applet-lrc-git
# или через paru
paru -S plasma6-applet-lrc-git
```

### Быстрая установка скриптом

```bash
git clone https://github.com/skippingclass/plasma-lrc.git
cd plasma-lrc
./install.sh                # сборка, установка в систему и перезапуск plasmashell
./install.sh --no-restart   # сборка и установка без перезапуска оболочки
./uninstall.sh              # полное удаление виджета и настроек
```

### Ручная сборка через CMake и Ninja

```bash
git clone https://github.com/skippingclass/plasma-lrc.git
cd plasma-lrc
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
sudo cmake --install build
systemctl --user restart plasma-plasmashell.service
```

### Запуск модульных тестов (CTest)

```bash
ctest --test-dir build --output-on-failure
# Все 10 тестов проходят успешно (парсеры, лимиты, конвейер, кеш, синхронизация)
```

### Добавление виджета на панель
1. Правый клик по панели Plasma → **Добавить виджеты…**
2. Найдите **Plasma LRC** и перетащите его в нужное место панели.

## Действия контекстного меню

Правый клик по виджету на панели:

| Действие | Описание |
|:---|:---|
| **Choose another match…** | Открывает интерактивный диалог поиска альтернативных текстов по всем провайдерам. |
| **Use automatic selection** | Сбрасывает ручной выбор и возвращает трек в автоматический конвейер провайдеров. |
| **Open song lyrics…** | Открывает окно чтения полного текста без таймкодов и караоке-разметки. |
| **Copy current lyric line** | Копирует текущую строку песни в буфер обмена (для LRCLIB и локальных файлов). |
| **Discard lyrics for this track** | Временно скрывает текст текущей песни без изменения черного списка. |
| **Restore lyrics for this track** | Восстанавливает временно скрытый текст песни из кэша. |
| **Blacklist current track lyrics** | Добавляет песню или артиста в постоянный черный список. |
| **Diagnostics…** | Открывает окно детальной телеметрии поиска и синхронизации. |
| **Configure Plasma LRC…** | Открывает настройки виджета и управление конвейером источников. |

## Настройки

Правый клик по виджету на панели → **«Настроить виджет...»**:

### Вкладка «Внешний вид» (Appearance)

| Параметр | По умолчанию | Описание |
|:---|:---:|:---|
| **Поющееся слово** | `Подчёркивание` | Стиль караоке: `Подчёркивание`, `Жирный`, `Цвет выделения`, `None` (построчное чтение) или `Sung words become white` (не спетые слова серые, спетое слово загорается белым). |
| **Цвет выделения** | *(Акцент KDE)* | Кастомный цвет активного слова. Кнопки-пресеты: Spotify (`#1ed760`), Cyan (`#00d4ff`), Purple (`#b342f5`), Yellow (`#ffd600`), Coral (`#ff4d4d`), White (`#ffffff`). |
| **Анимация** | `Включено` | Плавное затухание/появление текста при смене строк с сохранением белой подсветки. |
| **Бэк-вокал** | `Отключено` | Отображение вторичной строки бэк-вокала в скобках с независимым пословным синком. |
| **Выравнивание** | `По центру` | Выравнивание текста в виджете: `По центру` или `Слева`. |
| **Credit layout** | `Right of lyrics` | Расположение атрибуции на панели для источников Spicy API: `Right of lyrics` (справа от текста, по умолчанию) или `Below lyrics` (под текстом, для стандартных панелей от 30px). |
| **Макс. длина** | `40 символов` | Ограничение длины строки в символах для экономии места на панели (0 = без ограничений). |
| **Текст-заглушка** | `♪` | Что отображать на панели, когда ничего не играет. |
| **Паузы и интро** | `Отключено` | Показывать ноту-заглушку во время интро и инструментальных пауз (при отключении панель остаётся чистой). |
| **Иконка и подсказка** | `Включено` | Отображение ноты на панели и подробной подсказки трека с плеером и источником. |

| Параметр | По умолчанию | Описание |
|:---|:---:|:---|
| **Частота опроса** | `2000 мс` | Интервал проверки состояния плееров (500–10000 мс). |

| **Привязать к плееру** | *(пусто)* | Работать исключительно с указанным плеером и игнорировать остальные. |
| **Сдвиг тайминга** | `0 мс` | Корректировка (−2000…+2000 мс) для спешащих или отстающих треков. |
| **Игнорировать** | *(пусто)* | Список MPRIS-источников через запятую (например, плееры уведомлений). |

## Безопасность и хранение кэша

- **Потоковые лимиты размера**: Все сетевые загрузки контролируются потоковым сторожем, который мгновенно прерывает передачу данных при превышении **8 МиБ**, защищая память и сеть.
- **Защита от декомпрессионных бомб**: Парсеры архивов и Zlib блокируют распакованные полезные нагрузки свыше **16 МиБ**.
- **Строгий срок жизни кэша (30 дней)**: Локально сохранённые ответы API удаляются не позднее 30 дней с момента записи.
- **Отсутствие утечек учетных данных**: Окно диагностики и функция копирования отчета маскируют любые секретные ключи, токены и заголовки авторизации.

## Если что-то не работает

<details>
<summary><strong>Панель пустая, хотя музыка играет</strong></summary>

1. Убедитесь, что ваш медиаплеер поддерживает стандарт MPRIS2 (например, Spotify, Strawberry, Cider, VLC, Firefox, Chrome).
2. Если открыто несколько плееров, укажите нужный в **Настройки → Текст → Любимый плеер** (например, `spotify`).
3. Откройте **Правый клик → Diagnostics…**, чтобы проверить, поступают ли метаданные в виджет.
</details>

<details>
<summary><strong>Слова не подсвечиваются пословно</strong></summary>

1. Проверьте, есть ли пословная синхронизация для данного трека: **Правый клик → Choose another match…** (должен быть бейдж **Word**).
2. Если доступна только построчная синхронизация (**Line**), текст будет плавно отображаться по строкам.
3. Для пословного синка Spotify через Spicy Lyrics убедитесь, что клиентский ключ указан на вкладке **Источники**.
</details>

<details>
<summary><strong>Слова спешат или отстают от звука</strong></summary>

Откройте **Настройки → Текст** и отрегулируйте ползунок **Сдвиг тайминга** (−2000 мс…+2000 мс) с шагом в 50 мс для идеального попадания в такт.
</details>
